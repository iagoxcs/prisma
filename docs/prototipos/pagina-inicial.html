Fluxo de trabalho

Qual ferramenta usar em cada etapa do projeto

  1. Planejamento

    Miro para o levantamento inicial. Prisma para estruturar o projeto com tarefas e prazos.

  2. Execução

    Fireflies registra as reuniões, Target Normas valida a conformidade e o assistente no Discord guarda o contexto.

  3. Comunicação

    Canva e Gamma para apresentações. Relatório de status do Prisma para o cliente.

  4. Entrega

    Prisma consolida entregas, indicadores e o histórico do projeto para os próximos trabalhos.

Boas práticas

Combinados de uso das ferramentas

Segurança da informação

  • Não compartilhe credenciais com terceiros.
  • Faça logout em dispositivos compartilhados.
  • Trate dados de projeto com o assistente só por mensagem direta.

Produtividade

  • Atualize suas tarefas no Prisma todos os dias.
  • Crie templates reutilizáveis no Canva e no Gamma.
  • Mantenha os quadros do Miro organizados e arquive os finalizados.

Colaboração

  • Converse sobre o projeto no canal dele no Discord.
  • Marque os colegas envolvidos para dar visibilidade.
  • Registre decisões e aprendizados no contexto do projeto.
Suporte

Primeiros passos e dúvidas frequentes

Primeiros passos

  1. Receba o convite. O administrador cadastra seu e-mail corporativo.
  2. Defina sua senha. O link chega por e-mail.
  3. Assista à pílula 1. Um minuto para entender o acesso e o menu.
  4. Vincule o Discord. Em Minha conta, para usar o assistente.

Dúvidas frequentes

Não recebi o convite. O que faço?

Confira a caixa de spam e peça o reenvio ao administrador.

O cliente consegue ver todo o projeto?

Não. O convidado externo vê e atualiza apenas as tarefas atribuídas ou compartilhadas com ele.

O assistente não trouxe os dados no canal. Por quê?

Dados de projeto só são tratados por mensagem direta. Abra uma conversa privada com o assistente.
